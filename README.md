<summary><b>⚙️ One-time setup: enabling the contribution snake animation</b></summary>

1. In the `Tushar-2626/Tushar-2626` repo, go to **Actions → New workflow → set up a workflow yourself**.
2. Name the file `snake.yml` and paste:

```yaml
name: Generate Snake
on:
  schedule:
    - cron: "0 */12 * * *"
  workflow_dispatch:
  push:
    branches: [ main ]

permissions:
  contents: write

jobs:
  generate:
    runs-on: ubuntu-latest
    steps:
      - uses: Platane/snk/svg-only@v3
        with:
          github_user_name: Tushar-2626
          outputs: |
            dist/github-contribution-grid-snake.svg
            dist/github-contribution-grid-snake-dark.svg?palette=github-dark
      - uses: crazy-max/ghaction-github-pages@v4
        with:
          target_branch: output
          build_dir: dist
        env:
          GITHUB_TOKEN: ${{ secrets.GITHUB_TOKEN }}
```

3. Commit the file, then run it once manually from the **Actions** tab (`Run workflow`).
4. The snake SVG will populate within a few minutes and auto-refresh every 12 hours after that.
